# Поиск дешёвых рейсов Москва → Барселона

## Установка

```bash
pipx install flights
```

## Запуск

```bash
python search_mow_bcn.py
```

## Что ищет скрипт

- **Маршрут**: Москва (SVO/DME/VKO) → Барселона (BCN)
- **Период**: 20 мая — 10 июня 2026
- **Пересадки**: максимум 1
- **Класс**: эконом
- **Тип**: туда-обратно (7 дней) + в одну сторону

## Ручной поиск через CLI

```bash
# Дешёвые даты (туда-обратно, 7 дней, макс 1 пересадка)
fli dates SVO BCN --from 2026-05-20 --to 2026-06-10 -d 7 -R -s 1 --sort

# Конкретные рейсы на дату
fli flights SVO BCN --date 2026-05-29 --return 2026-06-05 -s 1 --sort CHEAPEST

# Без пересадок (если есть)
fli flights SVO BCN --date 2026-05-29 --return 2026-06-05 -s 0 --sort CHEAPEST
```
