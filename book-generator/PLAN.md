# AI Book Generator — план проекта

## Концепция

Генератор полноценных книг (художественных и профессиональных) через AI. Пользователь описывает идею — AI создаёт структуру, фабулу и генерирует главы. Первая глава бесплатно, остальные за деньги.

Фишка: AI не теряет сюжет и контекст между главами (в отличие от ChatGPT, который забывает через 5 сообщений).

---

## Бизнес-модель

### Бесплатно (онбординг):
- Описание книги + жанр + параметры
- Полное оглавление / фабула (несколько страниц)
- Аннотация
- Обложка (NanoBanana AI)
- **Первая глава целиком**
- Публикация на сайте (лента книг)

### Платно:
- **Каждая следующая глава** — фиксированная цена (напр. 99-199₽)
- **Вся книга сразу** — скидка (напр. 990₽ за 10 глав)
- Редактирование главы (попросить AI переписать/изменить)
- Отключить публикацию на сайте (приватная книга)
- Удалить книгу с сайта
- Экспорт в PDF/EPUB

### Допродажи:
- Профессиональный редактор (ручная вычитка)
- Озвучка книги (TTS)
- Иллюстрации к каждой главе

## Архитектура

### Стек:
- **Frontend**: Next.js 14 + Tailwind + shadcn/ui
- **Backend**: Next.js API routes + Prisma ORM
- **DB**: PostgreSQL (Supabase или Neon)
- **AI**: Anthropic API (Sonnet для генерации глав, Haiku для аннотаций/мета)
- **Обложки**: KIE.AI NanoBanana API
- **Оплата**: ЮKassa (RU) + Stripe (INT)
- **Деплой**: Vercel

### Сущности в БД:

```
User:
  id, email, name, plan (free/paid), credits, created_at

Book:
  id, user_id, title, genre, description, annotation
  outline (JSON — структура книги)
  cover_url (обложка NanoBanana)
  is_published (boolean, default true)
  language, status (draft/generating/complete)
  created_at, updated_at

Chapter:
  id, book_id, number, title
  content (text — сгенерированный текст главы)
  is_paid (boolean)
  is_generated (boolean)
  word_count, created_at

Payment:
  id, user_id, book_id, chapter_id
  amount, currency, status, provider
  created_at
```

### AI-агент (ключевая архитектура):

Проблема: ChatGPT/Claude теряют контекст на длинных текстах.

Решение: **многоуровневый контекст**

```
Уровень 1: Book Blueprint (всегда в контексте)
  - Жанр, тон, целевая аудитория
  - Полное оглавление с кратким описанием каждой главы
  - Список персонажей с характеристиками
  - Ключевые сюжетные линии
  - Стилистические правила

Уровень 2: Chapter Context (при генерации главы)
  - Blueprint (Уровень 1)
  - Краткое саммари предыдущих глав (по 2-3 предложения)
  - Полный текст предыдущей главы
  - План текущей главы из оглавления
  - Незакрытые сюжетные линии

Уровень 3: Edit Context (при редактировании)
  - Blueprint + текущая глава + инструкция от юзера
```

Модели:
- **Sonnet 4.6** — генерация глав (качество + цена)
- **Haiku 4.5** — аннотации, мета-данные, саммари
- **NanoBanana** — обложки

## Страницы сайта

### 1. Лендинг (/)
- Hero: "Напиши книгу с помощью AI — от идеи до готовой книги за вечер"
- Как это работает (3 шага)
- Примеры книг (лента)
- Тарифы
- Отзывы (адаптированные под гео: RU/EN)
- Отзывы адаптированные под жанр: бизнес/художка/нон-фикшн
- FAQ
- Мультиязычность (RU/EN)

### 2. Создание книги (/create)
- Шаг 1: Выбор жанра (художка/бизнес/нон-фикшн/учебник/мемуары)
- Шаг 2: Описание идеи (текстовое поле + подсказки)
- Шаг 3: Параметры (объём, тон, ЦА, язык)
- Шаг 4: AI генерирует оглавление + фабулу (бесплатно)
- Шаг 5: Подтверждение → генерация первой главы (бесплатно)

### 3. Редактор книги (/book/:id)
- Список глав (сгенерированные + заблокированные)
- Читалка главы
- Кнопка "Сгенерировать следующую главу" (платно)
- Кнопка "Изменить главу" (чат с AI)
- Настройки публикации
- Экспорт PDF/EPUB

### 4. Лента книг (/books)
- Публичные книги с обложками
- Фильтр по жанру, языку
- Каждая книга: обложка + аннотация + первая глава
- Клик → страница книги

### 5. Страница книги (/book/:id/read)
- Обложка, аннотация, автор
- Первая глава (бесплатно)
- Остальные главы → CTA "Разблокировать"

### 6. Личный кабинет (/dashboard)
- Мои книги
- Баланс / кредиты
- История платежей

## Монетизация цифры (прикидка)

- Себестоимость главы (~3000 слов, Sonnet): ~$0.03-0.05
- Цена главы для юзера: 99-199₽ (~$1-2)
- Маржа: ~95%+
- Средняя книга: 10-15 глав → 990-2985₽ с юзера
- При 100 книг/мес = 99K-298K₽/мес

## Конкурентные преимущества

1. **Не теряет контекст** — Blueprint + саммари предыдущих глав
2. **Обложка из коробки** — NanoBanana генерирует
3. **Публикация на сайте** — мотивация дописать + виральность
4. **Мультиязычность** — EN + RU из коробки
5. **Редактирование** — можно попросить AI переписать любую главу
6. **Дешевле конкурентов** — от 99₽ за главу
